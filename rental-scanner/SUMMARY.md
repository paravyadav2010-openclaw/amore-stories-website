# Rental Scanner - Project Summary

## ✨ What I Built

A fully-automated rental property discovery service that:
1. **Scans** rental sites daily (Domain.com.au, Trade Me)
2. **Filters** by quality, price, location
3. **Scores** properties by value (price/bedroom, location quality, new listing bonus)
4. **Generates** newsletters with top picks
5. **Distributes** via Telegram (with email coming soon)
6. **Monetizes** via premium subscriptions

## 📊 What It Does

### Daily Automation
1. **9:00 AM** → Cron triggers scanner.py
2. **9:01 AM** → Scans Domain.com.au for new listings
3. **9:02 AM** → Filters and scores properties
4. **9:03 AM** → Generates newsletter
5. **9:04 AM** → Saves to output/ (ready to post)

### Property Scoring
```
Total Score = (Price × 40%) + (Location × 30%) + (New Bonus × 10%)
```

- **Price Score:** Lower price/bedroom = higher score
- **Location Score:** Preferred suburbs = higher score
- **New Bonus:** Listings < 24h old = higher score
