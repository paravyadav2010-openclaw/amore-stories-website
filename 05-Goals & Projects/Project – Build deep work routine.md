# Project – Build Deep Work Routine

Status: active
Area: [[Personal Learning]]
Goal link: [[2025 Goals]]

## Outcome

By end of March 2025, I have a consistent daily deep work block (90 minutes, same time every day) that produces noticeable improvements in editing speed and quality.

## Why This Matters

Deep work blocks will reduce my editing time from 8 hours per photo session to 4–5 hours, freeing up time for client meetings and business growth.

## Plan

- Week 1: Choose my deep work philosophy (rhythmic – daily morning block)
- Week 1: Set the time (6–8am daily)
- Week 1: Create a starting ritual (clear desk, phone away, timer)
- Week 2–4: Build the habit, track consistency
- Week 4: Review results and adjust if needed
