# Attention residue hurts performance

Source: [[Deep Work - Cal Newport|Deep Work]]

## Explanation

Attention residue happens when I switch tasks before finishing the first one. My attention lingers on the previous task, making me perform worse on the new one. If I stop editing photos to check email, then return to editing, my work quality drops. This explains why context switching is so costly for my photography business.
