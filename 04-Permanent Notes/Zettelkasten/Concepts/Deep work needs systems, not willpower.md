# Deep work needs systems, not willpower

Source: [[Deep Work - Cal Newport|Deep Work]] – Part 2, Rule 1

## Explanation

Deep work is difficult because it requires intense mental effort and willpower. But willpower is limited—it gets weaker as the day goes on. Instead of relying on willpower to suddenly start focusing, you should build fixed routines and rituals (set times, places, and starting rituals). When deep work is automatic, you need much less willpower to begin. Smart systems make deep work sustainable over months and years.

## How I Can Use This

For my photography business: Set a fixed time each morning (e.g. 6–8am) for editing. Use the same desk, close email, same starting ritual. After a few weeks, editing at that time becomes automatic.
